# 기획안 (Phase 1)
**고객사:** iM라이프 DAX팀 | **작성일:** 2026-06-16 | **버전:** v1.2

## 1. 고객사 리서치 요약

### [추진 동력]
iM라이프는 박경원 대표 취임 이후 **'리뉴얼(Renewal) iM라이프'**를 핵심 키워드로 설정하고, 중소형 보험사 한계를 극복하기 위한 전사 구조 개편을 진행 중이다.

**영업 구조 전환:**
- 기존 전속 채널 없이 GA(보험대리점) 중심 영업 → **100% B2B 사업 모델로 완전 전환**
- 단기납 변액보험 일변도 탈피 → 장기납 보장성 보험(체증형 종신) + 연금 시장 공략으로 수익 구조 다변화
- CSM(계약서비스마진) 상승세 확인 → 영업 모델 혁신 효과 가시화

**DAX팀 신설 배경:**
2026년 운영혁신본부 산하에 **DAX(Digital & AI Transformation)팀을 신설**했다. '현업 + IT 경계 없이 유기적으로 융합한다'는 포부 아래, 반복적이고 정밀함이 요구되는 보험 핵심 업무를 AI 체계로 전환하는 구심점 역할을 맡겼다.

| 항목 | 내용 |
|---|---|
| 소속 | 운영혁신본부 산하 |
| 파일럿 대상 | ① 상품 IT 설계 ② 수수료 정산 ③ 수금 업무 |
| 중장기 목표 | 파일럿 성과 검증 후 전사 프로세스 확대 적용 (DAX팀이 확산 주체) |

**보험업 환경 압박:**
- K-ICS 비율 관리 + IFRS17 가이드라인 강화로 자본관리 효율화 필수
- 금리 인하 기조 속 보험손익 확대 + 운영비용 절감이 동시 과제
- **운영 자동화를 통한 비용 구조 개선**이 DAX팀 신설의 핵심 비즈니스 논리

### [실행 단계]
팀 신설 직후 → **빠른 실전 역량 내재화가 최우선 과제**

- 사내 LLM 없음 → 외부 LLM(Claude·ChatGPT) 활용 중심으로 체계 직접 구축
- 팀원 20명 / 현업 + IT 혼합 → 개발 수준 편차 존재 (Python 가능자 + 미경험자 혼재)
- 파일럿 3종 업무 AI 즉시 적용 역량 필요
- **보험 데이터 보안 특수성**: 실데이터 외부 LLM 입력 불가 → 더미 데이터 기반 실습 설계 필수

### [예상 허들]
1. **수준 편차 리스크**: Python 능숙자와 미경험자 혼재 → 보조 강사 1인 순회 코칭으로 속도 편차 최소화 (Claude Code는 코딩 없이 자연어 지시 중심으로 설계)
2. **신설팀 공백**: 자동화 타깃 업무가 아직 불명확한 팀원 존재 → 오리엔테이션 시 타깃 업무 카드 선정으로 자유 실습 시간 낭비 방지
3. **보안 제약**: 실데이터 활용 불가 → 더미 데이터 실무 전이율 설계로 보완
4. **도구 스택 밀도**: Chat → Cowork → Claude Code 3레이어를 8H 안에 전부 체득해야 하는 고밀도 설계 → 각 도구 실습 직후 즉시 산출물 생성으로 체감 성취감 확보

## 2. 전략 포지셔닝

### 핵심 포지션
> **"중소형 보험사 운영 한계를 Claude 생태계로 돌파하는 실전 파트너"**
> 이론 강의가 아닌 **파일럿 업무에 즉시 적용되는 자동화 결과물**을 하루 만에 구현

### 3대 차별화 전략

| 차별점 | 내용 | iM라이프 DAX팀 연결고리 |
|---|---|---|
| **Claude 생태계 전문성** | Chat → Cowork → Claude Code 3레이어 연계 체계 직접 실습 | 알파코 유료 계정 제공 + 성수 캠퍼스 Cowork 사전 설치 완료 |
| **보험 업무 특화 설계** | 수수료 정산·수금·상품 설계 더미 데이터 3종 사전 제작 — 실데이터 보안 제약 Zero 영향 | 파일럿 3종 업무 즉시 전이 가능한 실습 구조 |
| **전사 확산 자산화** | 교육 산출물을 템플릿·스크립트·워크플로우로 남겨 타 부서 공유 가능 형태 설계 | DAX팀의 전사 확산 주체 역할 직접 지원 |

- **스타일:** 실습/결과 중심 실전형 (Heavy)
- **근거:** 개발 지식 보유자 포함 집단 + 이론 최소화 명시 요구 + 1일 8H 고밀도 실습

## 3. 교수설계 모델 선택

| 항목 | 내용 |
|---|---|
| **선택 모델** | **SAM 모델 (Successive Approximation Model — 애자일 교수설계)** |
| **선택 근거** | 빠른 프로토타입 구현 → 반복 피드백 → 개선의 루프가 Claude 도구 실습 구조와 정확히 일치. 보조 강사 순회 코칭과 결합 시 수준 편차 최소화 |
| **매핑 변수** | 목표 유형 O=2(도구 숙달·실습), 교육 기간 D=1(1일), 산출물 = 실물 스크립트·워크플로우 |

## 4. 커리큘럼 — 8H 타임라인

**교육 대상:** iM라이프 DAX팀 20명 | **개발 수준:** 혼재 (공통 커리큘럼 단일 트랙)
**교육장:** 알파코 성수 캠퍼스 | **계정:** 알파코 제공 Claude 유료 계정
**강사 구성:** 주강사 1인 + 보조 강사 1인 (수준 편차 대응)
**도구 체계:** Claude Chat → Cowork → Claude Code (단계별 자동화 레이어 공통 실습)
**최종 산출물:** 1인 1개 이상 실무 자동화 워크플로우 (재사용·공유 가능 형태)

> **설계 원칙:** 이론 1H 이내 압축. '직접 만들고 가져가는' 구조. 발표 세션 없음 — 강사 순회 코칭.
> 보험 실데이터 외부 LLM 입력 불가 → 알파코 제작 더미 데이터 전면 활용.
> A/B 시나리오 분리 없음 — 코딩 여부 무관하게 자연어 지시로 전원 동일 도구 실습.

## 6. 도구 체계 — Claude 생태계 3레이어

```
Layer 1 — Claude Chat (프롬프트 기반 업무 자동화)
  └─ 세션 2: 수수료 정산 보고서 초안 / 프롬프트 표준화 / Claude Project 팀 컨텍스트 고정

Layer 2 — Cowork (로컬 파일 자동화 위임)
  └─ 세션 3: 수수료 CSV 10개 자동 집계 + 수금 현황 CSV 12개 미납 추출

Layer 3 — Claude Code (에이전트 설계)
  └─ 세션 4: 상품 설계 Excel 자동 정제 + CLAUDE.md 업무 지침 템플릿 생성

[파일럿 업무 매핑]
  수수료 정산 → Layer 1 + Layer 2 (세션 2 + 3)
  수금 업무   → Layer 2 (세션 3)
  상품 IT 설계 → Layer 3 (세션 4)
  개인 업무   → Layer 자유 선택 (세션 5 자유 실습)
```
