## 2. 고객사 컨텍스트

- **업종·규모:** 중소형 보험사 / iM뱅크(구 DGB금융) 계열 생명보험사
- **DAX팀 신설 배경:** 2026년 운영혁신본부 산하 DAX(Digital & AI Transformation)팀 신설 — 박경원 대표 추진 '디지털·AI 전환을 통한 중소형 보험사 한계 극복' 전략의 핵심 실행 조직
- **팀 미션:** 현업 + IT 경계 없이 융합, 주요 현업 업무를 디지털·AI 체계로 전환하는 구심점
- **중장기 목표:** 전사 인력의 IT 인재화 / 보험 본업 전 프로세스에 DAX 적용
- **파일럿 대상 3종:** ① 상품 IT 설계 ② 수수료 정산 ③ 수금 업무
- **전사 확산 역할:** 파일럿 성과 검증 후 전 부서로 확대 적용 (DAX팀이 확산 주체)

### 팀원 특성 [수정됨]

| 구분 | 인원 | 기술 스택 | AI 도구 현황 |
|---|---|---|---|
| **개발직군** | 3명 | Java, JS, 이클립스 | Claude Code 주로 사용 중 (기사용) |
| **현업직군** | 3명 | 보험업무 전반 (상품·고객·운영) | 도구 경험 상대적으로 낮음 |

**핵심 교육 방향 [수정됨]:** 개발자 위주 교육이 아닌, **현업과 개발이 함께 쓸 수 있는 협업 중심 교육**
- 개발직군: Claude Code 기사용 → 현업 연동 방식·협업 워크플로우 심화
- 현업직군: Claude Chat + Cowork 중심, 개발직군이 만든 결과물을 활용하는 방법 체득
- 일반직원 대상 교육은 별도 편성 (이번 과정 범위 밖)

| GenAI 기초 과정 | **생략** — DAX팀은 바로 자동화 실습 레벨 진입 |

## 3. 제안서 조건

- **제출 기한:** 2026-06-20 (이번 주) — 긴급
- **경쟁 여부:** 미확인
- **강조 포인트:**
  - 단순 툴 소개가 아닌 **실무 자동화 결과물 직접 구현** 중심
  - 파일럿 업무(상품 IT 설계·수수료 정산·수금)에 즉시 적용 가능한 실습
  - 교육 산출물이 **다른 부서에 공유·확산 가능**한 재사용 자산
  - DAX팀 전사 확산 주체 역할 맥락 강조
- **금지 사항:**
  - 강사 개인 이름·약력
  - 실제 보험 데이터 외부 LLM 입력 — 더미 데이터 활용 필수

## 4. 도구·환경 상세

| 구분 | 내용 |
|---|---|
| 교육장 | **알파코 성수 캠퍼스** |
| Claude 계정 | **알파코 제공 유료 계정** (Pro/Team) — 실습 전 범위 커버 가능 |
| Cowork | **설치 가능 확인** — 실습 범위 포함 |
| Claude Code | 포함 (VS Code 연동, 환경 사전 설치 안내 필요) |
| 사내 LLM | 없음 → Claude·ChatGPT 외부 LLM 활용 |
| 사내 PC | 외부 접속 제한 → **개인 노트북 지참** 또는 알파코 캠퍼스 PC 활용 |
| 개인 디바이스 | 접속 가능 — 사전 안내 필요 |
| 더미 데이터 | 실제 보험 데이터 외부 LLM 입력 불가 → 알파코 가상 데이터 사전 제작 |

### 더미 데이터 설계 방향

| 데이터셋 | 포함 컬럼 | 의도적 오류 (실습용) | 활용 실습 |
|---|---|---|---|
| 수수료 정산 CSV (10개 파일) | 대리점명, 상품코드, 계약건수, 수수료율, 수수료금액, 정산월 | 금액 단위 불일치, 결측치, 대리점명 표기 오류 | 실습 ②③ |
| 수금 현황 CSV (월별 12개) | 계약번호, 고객명, 납입보험료, 납입일, 미납여부, 담당GA | 날짜 형식 혼재, 미납 표기 불일치 | 실습 ③ |
| 상품 설계 더미 (Excel) | 상품코드, 상품명, 보장내용, 보험료, 갱신주기, 적용조건 | 중복 행, 보험료 이상값 | 실습 ④ |

## 5. 커리큘럼 방향 원칙

| 원칙 | 내용 |
|---|---|
| 이론 최소화 | 개발 지식 보유자 포함 대상 → 이론 1H 이내. 도구 원리보다 '어떻게 업무에 쓰는가'에 집중 |
| 실습 중심 (6~7H) | '직접 만들고 가져가는' 구조. 강의 후 결과물 확보 목적 |
| 보험 업무 맥락 일치 | 수수료 정산·수금·상품 설계 더미 데이터 기반 실습 → 실무 전이율 극대화 |
| 재사용 가능 자산화 | 산출물이 템플릿·스크립트·워크플로우 형태 → 타 부서 공유 가능 |
| 발표 없음, 코칭 있음 | 발표 세션 제거 → 자유 실습 시간 강사 순회 코칭 |
| 수준별 대응 | **현업+개발 협업 구조** — 동일 도구(Claude Chat·Cowork)를 현업은 업무 지시자로, 개발은 구현 검증자로 함께 사용. 개발직군 Claude Code 심화는 현업 연동 시나리오 중심으로 구성 [수정됨] |

## 6. 도구 체계 (Claude Ecosystem 중심)

```
[도구 레이어]
Claude Chat (프롬프트 기반 업무 자동화)
    ↓
Cowork (로컬 파일 자동화 위임)
    ↓
Claude Code + MCP (에이전트 구성 / 상품 설계 자동화)
```

- **단일 트랙 (공통):** Claude Chat → Cowork → Claude Code (자연어 지시 중심 — Python·코딩 지식 불필요)
- Anthropic API 미사용 (알파코 제공 Claude 유료 계정으로 전 세션 커버)
