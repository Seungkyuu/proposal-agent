Track 3ㅣAM. DAX팀 협업 자동화 — 협업 구조 설계 · Claude Chat · Cowork

현업·개발이 Claude Chat과 Cowork를 공통 도구로 삼아 보험 업무 자동화 워크플로우를 페어로 직접 구현하는 오전 실전 세션

학습목표

  1. Claude 생태계 3레이어를 DAX팀 협업 구조에 매핑하고, 현업·개발 역할과 파일럿 업무를 페어로 직접 확정한다

  3. Cowork로 수수료 정산·수금 파일 자동화를 페어로 직접 구현하여 즉시 재실행 가능한 워크플로우 2건을 확보한다

Track 3ㅣPM. DAX팀 협업 자동화 — Claude Code 심화 · 파일럿 페어 프로그래밍

Claude Code와 현업 자연어 요구사항을 연결하는 페어 구현 루프를 체득하고, 자유 실습에서 파일럿 자동화 워크플로우를 완성하여 전사 확산 자산으로 포장하는 오후 실전 세션

학습목표

  1. Claude Code와 현업 자연어 요구사항을 연결하는 3단계 페어 구현 루프(정의→생성→검토)를 직접 체득하고 DAX팀 전용 CLAUDE.md를 완성한다
  2. 수수료 정산·수금·상품 설계 중 파일럿 업무를 선택하여 Chat·Cowork·Claude Code를 자유 조합, 자동화 워크플로우를 페어로 직접 완성한다
  3. 완성 워크플로우에 README를 추가하여 타 팀원·일반직원이 재사용 가능한 전사 AX 확산 자산으로 포장한다
