## 2. 고객사 컨텍스트

- **업종·규모:** 종합 물류·모빌리티 솔루션 기업 / 현대자동차그룹 계열 / 국내외 임직원 수천 명 규모
- **의사결정자:** 오재영 매니저 / 교육문화팀
- **최근 AI·DX 행보:** 전사 AX(AI Transformation) 선언, 'AX컬리지' 자체 교육 브랜드 수립
- **주요 업무 목록 (실습 소재):**
  - 물류 운영 보고서, 공급망(SCM) 현황 분석
  - 해상·항공·육운 운송 계획 및 실적 관리
  - 글로벌 법인 대상 업무 지시·보고 문서
  - Excel 기반 물동량·비용·KPI 데이터 분석
  - 팀장급: AI 기반 물류 의사결정 및 조직 전환 전략

## 3. 제안서 조건

- **제출 기한:** 2026-06-11 (오늘) — 긴급
- **경쟁 여부:** 경쟁 입찰 (3~4개 기업 동시 제안)
- **강조 포인트:**
  - 단순 이론이 아닌 현업 적용·자동화 결과물 도출 중심
  - 실제 업무 데이터 및 사례 기반 실습 구성
  - 연계 교육 체계: 과정 1 → 과정 2 → 과정 3 순차 이수 구조 (과정 4는 팀장급 독립 운영)
  - **선수과정 미이수자 진입 허용 (확정):** 앞 단계를 이수하지 않은 수강 희망자도 사전 역량 테스트 통과 시 해당 과정 수강 가능
    - 과정 2 직접 수강 희망 → 과정 1 수준 역량 테스트 통과 필수
    - 과정 3 직접 수강 희망 → 과정 2 수준 역량 테스트 통과 필수
    - 과정 4(리더십) → 선수과정 무관, 팀장급 직급 조건만 적용
- **금지 사항:**
  - 강사 개인 이름·약력 (수행 실적 방식으로 대체)
  - H-Chat (현대그룹 내부 AI 챗봇) 실습 도구 포함 금지
  - KHP(현대그룹 HR 플랫폼) 연동 내용 기재 금지
- **KPI·사후관리 납품 범위 (확정):** Level 1 만족도 조사만. Level 2~4 미포함.
- **총 예산:** 5,000만 원 (견적은 담당자 별도 작성 — 전략 참고용으로만 활용)
