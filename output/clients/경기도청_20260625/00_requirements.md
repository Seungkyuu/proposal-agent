## 2. 고객사 컨텍스트
- **업종·규모:** 광역지방자치단체 (경기도 행정). 본청 임직원 대상.
- **의사결정자:** 미정 (공개 가능 범위 내 추후 확인)
- **최근 AI·DX 행보:** Phase 1 웹 리서치에서 경기도청 AI·DX 정책/선언 확보 예정
- **공동 제안:** SK AX와 공동 제안. 오프라인 실습은 알파코, 온라인 과정은 SK AX 플랫폼.
- **주요 업무 목록 (실습 소재 맞춤화):** 보고서 자동화, 규정집 업데이트, 정부24 활용 가능한 AI Agent 제작 등 실제 행정 업무 기반 실습

## 3. 제안서 조건
- **제출 기한:** 미정
- **경쟁 여부:** 단독/수의 제안 (SK AX 공동) — 신뢰·실행력 중심 피치
- **강조 포인트:**
  - 실제 업무 기반(보고서 자동화·규정집 업데이트·정부24 연동) 맞춤형 AI Agent를 직접 제작·완성하는 과정
  - 바이브코딩 입문부터 맞춤형 Agent 산출물 완성까지 짧은 시간 내 실전형 설계
- **금지 사항:**
  - 강사 개인 프로필(이름·약력·이력) 불포함
  - SK AX 인증제와의 **직접 연계 반영 금지** — 향후 연계 가능한 "연결고리"만 남김
  - 타 고객사명(신한은행·장금상선·한화 에어로스페이스 등) 슬라이드 직접 언급 금지 (실적 슬라이드 제외)
- **KPI·사후관리 납품 범위 (확정):** 미정 → 만족도 조사(Level 1) 기본 가정. Level 2~4는 별도 확인 필요.

## 4. 활용 가능 알파코 레퍼런스
| 고객사 | 용도 | 슬라이드 게재 |
|---|---|---|
| 장금상선 (AI Agent 73H, 6모듈) | **커리큘럼 뼈대 직접 기반** — 바이브코딩·Claude Code·MCP·Skills 흐름 | 일반 콘텐츠 미언급 / 실적 슬라이드 게재 가능 |
| 신한금융그룹·신한은행 (AX 혁신리더 80H) | **제안서 구조·설득 패턴 기반** — 4부 구성, 회차별 아웃풋 예시, 일일 학습흐름, 수준별 역량 프레임 | 일반 콘텐츠 미언급 / 실적 슬라이드 게재 가능 |
| 한화 에어로스페이스 (DX 역량강화) | 사용자 PPT 제작 시 **양식 참조** (에이전트 산출물에는 미반영) | 실적 슬라이드 게재 가능 |

> 위 고객사명은 일반 콘텐츠 슬라이드에서는 익명/미언급 처리한다.
> **단, 알파코 수행실적·레퍼런스 슬라이드에는 게재 가능**(Skill 규칙: "실적 슬라이드 외 금지"의 예외).

## 4-1. 커리큘럼 설계 방향 (Phase 1 리서치로 검증·확정)
- **운영 골격:** 24H = **6회차 × 4H, 주 1회 분산.** 장금상선 4H/회기 단위와 정합.
  주 1회 분산의 함의 — 회차 간 1주 간격을 활용해 "현업 과제 적용 → 다음 회차 피드백" 사이클 설계 가능(연속 집합 대비 강점).
- **뼈대(장금상선 6모듈 압축 기반, 회차 순서는 리서치 후 확정):**
  AI Agent 개념·Pain Point 도출 → 바이브코딩·개발환경 구축 → 데이터·문서 활용 → 핵심 구현 → 고도화 → 완성·발표
- **실습 예제·구현 목표는 리서치로 설계(확정 아님):**
  > 사용자가 언급한 "정부24 연동·보고서 자동화·규정집 업데이트"는 **가설**이다.
  > Phase 1에서 ① 경기도청 실제 업무·공개 데이터·민원 유형, ② 지자체 공무원 대상 AI Agent 실습의 기술적 타당성(정부24 연동 가능성·대안), ③ 25명 초중급 대상 4H×6회 분량 적합성을 웹/딥리서치로 검증한 뒤,
  > **정합성을 따져 실제 실습 예제와 회차별 구현 목표를 재설계**한다. 사용자 제안을 그대로 옮기지 않는다.
- **설득 패턴(신한 차용):** 회차별 "아웃풋 예시" 명시, 일일 학습흐름(Recap→실습→리뷰), 페인포인트→회차 매핑.
- **SK AX 연계:** 인증제 직접 반영 금지. 향후 연계 "연결고리"만 표기.
