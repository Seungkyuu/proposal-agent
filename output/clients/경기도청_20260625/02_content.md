 • 단일 행정서류 1종을 처리하는 미니 Agent 제작(요약·항목 추출)
 • Before–After 프롬프트 개선 실습으로 결과 품질 비교
실습 산출물: 동작하는 미니 Agent(문서 입력 → 핵심 항목 자동 추출)
AI 도구: Claude Code, Cursor | 4H

■ 3회차 — 다단계 워크플로우 설계 (교차검증 v1)
교육 내용:
 • 단발 생성 vs 다단계 워크플로우의 차이와 설계 원리
 • 신청서 ↔ 자격요건 대조 로직, 규칙 기반 판단·예외 처리
 • 판단 '근거'를 함께 제시하는 신뢰 설계
핵심 실습 활동:
 • 자격요건·구비서류 체크리스트를 규칙으로 구조화
 • 신청서 입력 → 요건 대조 → 누락·불일치·기한초과 자동 플래그 구현
 • 처리 결과에 근거 문장을 함께 출력하도록 설계
실습 산출물: 교차검증 Agent v1 (불일치 항목 자동 표시 + 근거 제시)
AI 도구: Claude Code | 4H

■ 4회차 — 다출처 데이터·규정 연결 (교차검증 v2)
교육 내용:
 • RAG 개념과 규정·기준 문서를 Agent에 연결하는 방식
 • 공공데이터포털(data.go.kr) Open API 구조와 호출 방법
 • 서류 + 규정 + 외부 데이터의 다출처 통합 설계
핵심 실습 활동:
 • 자치법규·내부 기준을 RAG/규칙으로 Agent에 연동
 • data.go.kr Open API 호출 → 판단 근거 데이터 보강
 • 사업·서식만 교체해 타 업무로 복제하는 구조화 실습
실습 산출물: 기준 연동형 교차검증 Agent v2 + 타 업무 복제용 설정
AI 도구: Claude Code, 공공데이터 Open API | 4H

■ 5회차 — 고도화·신뢰검증 + 심화 분기
교육 내용:
 • 환각(Hallucination) 발생 원인과 방지 전략
 • 결과 검증 체크리스트·근거 추적 설계, 보안(소버린) 활용 기준
 • (심화) 민원 인사이트·취합·모니터링형 파이프라인 개요
핵심 실습 활동:
 • 검증 체크리스트 적용 + 오류 시나리오 테스트로 정확도 점검
 • MCP·외부 도구 연동으로 Agent 기능 확장
 • 역량팀: 소속 부서 맞춤 심화 Agent로 분기 제작
실습 산출물: 검증 내장 Agent v3 / (심화) 부서 맞춤 Agent 초안
AI 도구: Claude Code, MCP | 4H

■ 6회차 — 완성·발표·팀 자산화 (PBL)
교육 내용:
 • 재사용 템플릿화 원칙(입력·규칙·검증 모듈 분리)
 • 산출물 패키징·간단 운영 가이드 작성법
 • 부서 확산 시나리오 및 AI국 연계 경로
핵심 실습 활동:
 • 실제 업무 데이터로 최종 디버깅·완성
 • 팀별 완성본 데모 발표 및 상호 피드백
 • 재사용 템플릿 + 사용설명서 작성으로 팀 자산화
실습 산출물: 실행 가능한 최종 Agent + 재사용 템플릿 + 발표자료
AI 도구: Claude Code | 4H

[하단 캡션]
※ 핵심 anchor(교차검증형)는 3~6회차에 걸쳐 누적 완성 → 전원 실행 가능한 Agent 1개 확보. 5회차에서 역량팀은 부서 맞춤 심화로 분기.
※ '업무 진단 워크숍'은 사전 별도 진행되므로 커리큘럼에서 제외(결과만 1회차에 활용).
