## 고객사 현황 분석

### As-Is (현재의 한계)
- AX 추진 선언 대비 실무직원 AI 도구 활용률 저조
- 부서별 데이터 분석·홍보 콘텐츠 제작 외주 의존도 高
- 민원 대응 자동화 필요성 인식은 있으나 자체 구현 역량 부재

### To-Be (교육 후 전환 성과)
- 공단 데이터 기반 현황 분석 보고서 직접 생성 가능
- 내부 홍보 콘텐츠(카드뉴스·숏폼) AI로 자체 제작
- 민원 FAQ 챗봇 프로토타입 직접 구현·운영

## 교수설계 철학

**역방향 교수설계 (Backward Design)** — "결과물 먼저 설계"

1. **산출물 합의**: 교육 종료 시 수강생이 손에 쥘 실물 결과물 스펙 사전 확정
2. **평가 기준 역산**: 도구 조작 숙련도가 아닌 결과물 완성도 기준 채점
3. **차시 역설계 배치**: 최종 산출물 달성에 필요한 스킬만 선별 (이론 20% : 실습 80%)

| C. AI 챗봇 구현 (8H) | Custom GPT로 민원 FAQ 챗봇 직접 배포 | 배포 가능 챗봇 프로토타입 + 운영 가이드북 |

## 알파코 3대 USP

1. **공공기관 전용 실습 데이터** — 공단 실제 운영 데이터로 실습, 교육 즉시 업무 적용
2. **초급 편차 대응 맞춤 설계** — 3-Level 속도 조절형 실습, 모든 수강생 완주 보장
3. **산출물 보장 성과 계약** — 과목별 최소 산출물 사전 계약, 미완성 시 보충 세션 무상 제공

## 평가 체계

**커크패트릭 4단계**
- Level 1: 반응 평가 (목표 4.5/5.0 이상)
- Level 2: 산출물 완성도 루브릭 심사
- Level 3: 4주 후 현업 활용 빈도 자기보고 (기본 제공)
- Level 4: 6개월 후 업무 시간 절감률 추적 (선택)
