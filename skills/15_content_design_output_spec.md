# Skill 15: 제안서 콘텐츠·디자인 통합 출력 명세

## 1. 개요

본 Skill은 Phase 3 완료 시 생성하는 `03_content.md`의 **정확한 출력 포맷**과
**카피라이팅 규칙**, **디자인 시스템 스펙**을 통합 정의한다.

Skills 02(색상), 03(톤앤매너), 07(카피라이팅)의 핵심 규칙이 여기에 통합된다.
Phase 3를 수행할 때 이 Skill을 최우선으로 참조한다.

---

## 2. 카피라이팅 필수 규칙

### 2-1. 절대 금지 어휘
아래 어휘는 어떤 텍스트에도 등장해서는 안 된다.

| 금지 | 대체 어휘 |
|------|---------|
| 이해 | 도출, 분석, 파악 → **적용**, **실전화** |
| 파악 | **진단**, **분석**, **가시화** |
| 학습 | **습득** 금지 → **체득**, **실전 구축** |
| 교육 | (단독 사용 금지) → **역량 강화**, **실무 전환** |
| 습득 | **내재화**, **체득**, **자동화** |

> 검증: 최종 출력 전 위 5개 단어가 0건인지 반드시 확인한다.

---

### 2-2. 상단 메시지 (Top Message) 작성 규칙

슬라이드 최상단 30pt 텍스트. **전체 슬라이드의 결론을 두괄식으로 압축.**

**구조 공식**
```
[고객사 당면 과제 or 현재 상황]
[핵심 솔루션 키워드 or 정량적 기대 효과]
```

**규칙**
- 1줄당 최대 22자. 반드시 2줄로 구성 (`\n` 줄바꿈 적용).
- 수치(%, 배, 시간, 건수) 또는 고객사명 1개 이상 포함 권장.
- 마침표 없음. 명사형 종결.

**예시**
```
❌ "AI 기술의 중요성이 높아짐에 따라 역량 강화가 필요합니다"
⭕ "박희수 이사장 선언 '디지털·AI 경영혁신'\n실현을 위한 실무 역량 Gap 해소 전략"

❌ "알파코의 강점을 소개합니다"
⭕ "타사와 차별화되는\n알파코 3대 독보적 강점 (USP)"
```

---

### 2-3. 카드 헤더 (18pt) 작성 규칙

- 명사형 완전 종결. **8자~14자** 이내.
- 번호 접두어 포함: `01. XX XX XX` 형식.
- 행동 지향 동사 명사화 적극 사용.

```
❌ "AI 기술을 활용하여 업무 효율을 높이는 방법"  (너무 길고 동사형)
⭕ "01. 공공기관 전용 실습 데이터"
⭕ "02. 초급 편차 대응 맞춤 설계"
⭕ "03. 산출물 보장 성과 계약"
```

---

### 2-4. 본문 불릿 (14pt) 작성 규칙

- 불릿 1개당 최대 **45자**.
- **대구형 문장** 구조 권장: `[A]를 통한 [B] 달성`, `[A] 기반의 [B] 자동화`
- 수치·구체성 필수: 막연한 표현 금지.

```
❌ "실습 위주로 구성되어 실무에 바로 적용 가능합니다"
⭕ "100% 실전 워크숍 구성 → 현업 복귀 즉시 개인 맞춤 솔루션 가동"

❌ "AI 활용 역량이 부족합니다"
⭕ "전사 AX 선언 대비 임직원 AI 직접 활용률 저조 — 실행 Gap 명확"
```

## 3. 디자인 시스템 자동 생성 규칙

### 3-1. 브랜드 컬러 리서치 (Phase 0 완료 직후 수행)

고객사명이 확정되면 **웹 서치**를 통해 브랜드 컬러를 확보한다.

```
1단계: WebSearch 실행 (3쿼리 병렬)
   - "{고객사명} CI 색상 코드"
   - "{고객사명} brand color HEX"
   - "{고객사명} 로고 색상"

2단계: 결과 해석
   - 공식 홈페이지 또는 CI 가이드라인 PDF에서 HEX/RGB 코드 확인
   - 검색 결과에서 색상명 추출 후 근사 HEX 변환 (예: "코발트 블루" → #1B5EA3)

3단계: 폴백 (검색 결과 없음 또는 불명확)
   a) 업종 기반 기본값 적용:
      공공기관/지자체    → #1B5EA3 (공공 블루)
      금융/은행          → #003087 (딥 네이비)
      테크/IT            → #2563EB (브라이트 블루)
      의료/공단          → #0F7B6C (딥 그린)
   b) 사용자에게 알림:
      "웹 서치 결과 HEX 코드를 확인하지 못해 업종 기본값 [HEX]을 적용했습니다.
       정확한 브랜드 컬러가 있다면 알려주시면 바로 교체합니다."
```

> **실행 타이밍**: Phase 0 완료 → Phase 1 시작 직전에 WebSearch 실행.
> 검색 결과는 `01_strategy.md` 하단 디자인 시스템 블록에 기록한다.

---

### 3-2. 4색 단일 팔레트 시스템

**원칙: 단순·통일·집중** — 전체 슬라이드에서 4개 색상만 사용한다.

| 역할 | HEX | 적용 대상 |
|------|-----|---------|
| **Background** | `#FFFFFF` | 모든 슬라이드 배경 |
| **Text (Main)** | `#1A1A2E` | 상단 메시지, 본문 불릿, 표 데이터 텍스트 |
| **Text (Secondary)** | `#6B7280` | 부제목, 캡션, 주석, 표 일반 행 텍스트 |
| **Accent** | `[고객사 브랜드 HEX]` | 카드/섹션 헤더 배경, 핵심 수치, 표 헤더 배경 |

**Accent 위 텍스트**: 항상 `#FFFFFF` (흰색)
**폴백**: 브랜드 컬러 미확인 시 → `#1B5EA3`

> 이 4개 이외의 색상은 어떤 슬라이드에도 추가하지 않는다.
> 색상 수를 늘리는 것은 통일성을 해친다.

---

### 3-3. 글꼴(폰트) 표준

| 텍스트 요소 | 크기 | 굵기 | 색상 |
|-----------|------|------|------|
| 상단 메시지 (Top Message) | **30pt** | Bold | `#1A1A2E` |
| 카드/섹션 헤더 | **18pt** | Bold | `#FFFFFF` (Accent 배경 위) |
| 본문 불릿 | **14pt** | Regular | `#1A1A2E` |
| 표 헤더 행 | **12pt** | Bold | `#FFFFFF` (Accent 배경 위) |
| 표 데이터 행 | **11pt** | Regular | `#6B7280` |
| 슬라이드 번호/캡션 | **10pt** | Regular | `#6B7280` |

**폰트 패밀리 우선순위**
1. `맑은 고딕` (Windows 기본 한글 — 가장 안전)
2. `Noto Sans KR` (웹 환경)
3. `나눔스퀘어 Neo` (설치 확인 후 사용)

```markdown

> 주제: [교육 주제]

## 디자인 시스템

| 역할 | HEX | 적용 대상 |
|------|-----|---------|
| Background | #FFFFFF | 슬라이드 배경 전체 |
| Text (Main) | #1A1A2E | 상단 메시지, 본문 불릿 |
| Text (Secondary) | #6B7280 | 캡션, 표 데이터, 부제목 |
| Accent | #[고객사 브랜드 HEX] | 카드/표 헤더 배경 (위 텍스트: #FFFFFF) |

| 요소 | 크기 | 굵기 |
|------|------|------|
| 상단 메시지 | 30pt | Bold |
| 카드/섹션 헤더 | 18pt | Bold |
| 본문 불릿 | 14pt | Regular |

| 표 데이터 | 11pt | Regular |
| 캡션 | 10pt | Regular |

폰트: 맑은 고딕

---
```
