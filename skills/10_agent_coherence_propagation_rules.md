# Agent Skill: Agentic Logic Coherence & Multi-Step Change Propagation Rules (V4. Clean Setup)

## 1. 개요 (Overview)
본 사양은 사용자가 8단계 파이프라인 진행 중 특정 단계(State)의 기획 내용을 수정하거나 업데이트했을 때, 해당 수정 사항이 연관된 모든 전·후방 단계의 데이터셋에 동적으로 전파(Propagation)되어 제안서 전체의 논리적 모순을 원천 차단하는 '에이전트 자가 정합성 유지 규칙'을 정의한다. 예산 및 강사진 변수는 배제한다.

---

## 2. 논리적 인과관계 맵 (Logical Dependency Map)

에이전트는 특정 변수 V가 수정되었을 때, 이에 영향을 받는 종속 변수들의 네트워크(Dependency Graph)를 상시 모니터링한다.

```
[수정 변수 (Input Edit)]
│
├── 1. 교육 대상(Target) 변경
│     ➔ [영향 영역] Step 4(교수설계 모델 재매핑), Step 5(커리큘럼 난이도 및 이론:실습 비율 재조정),
│                   Step 7(KPI 평가법: 초급→이해도/고급→성과 중심)
│
├── 2. 교육 기간(Duration) 변경
│     ➔ [영향 영역] Step 4(교수사태 적용 여부 재판단), Step 5(커리큘럼 차시 분량 재산정),
│                   Skill 06 Section 3-1(AS Gap 보완 옵션 A 연동)
│
├── 3. 교수설계법(Model) 변경
│     ➔ [영향 영역] Step 5(모듈 순서 및 실습 배치 재구성), Step 7(KPI 평가 모델 재선택)
│
├── 4. 고객사 도메인(Domain) 변경
│     ➔ [영향 영역] Step 1(고객사 리서치 쿼리 재실행 — Skill 01 Section 2 재가동),
│                   Step 5(도메인 실습 시나리오 재매핑 — Skill 05 Section 4 재적용)
│
├── 5. 현재 역량 레벨(Proficiency Level) 변경
│     ➔ [영향 영역] Step 5(Skill 05 Section 3의 이론:실습 비율 재조정),
│                   Step 7(KPI 평가 기준: 초급→반응/이해도 중심, 고급→행동변화/ROI 중심)
│
└── 6. 브랜드 컬러 재지정(Color Override)
      ➔ [영향 영역] Step 2(Skill 02의 60-30-10 팔레트 재계산),
                    Step 3(Skill 08 제안사 소개 슬라이드의 accent_color 동기화)
```

## 3. 동적 전파 알고리즘 및 복구 로직 (Propagation Protocol)

사용자가 특정 단계의 수정 데이터를 확정하는 즉시, 에이전트는 무조건 아래의 '체인 이펙트(Chain Effect)' 프로세스를 무대 뒤(Background)에서 구동시킨다.

### [체인 이펙트 실행 과정]
1. **수정 감지 (Diff Detection):**
   * 수정 전 데이터 D_old와 수정 후 데이터 D_new의 차이점을 파싱하여 영향도가 높은 핵심 키워드(예: "개발자" ➔ "임원진")를 식별한다.

2. **영향도 평가 (Impact Assessment):**
   * 의존성 그래프에 따라 재설계가 필요한 파이프라인 단계를 'Dirty' 상태로 마킹한다.

3. **순차적 자가 수정 (Cascade Refactoring):**
   * 마킹된 전·후방 단계들을 차례로 호출하여 컨텍스트를 동기화한다.
   * *예시 시나리오:* 사용자가 5단계 커리큘럼에서 "실전 데이터 연동 및 AI 코딩 구현"을 대규모로 추가하는 수정을 단행했을 때:
     - **역전파(Step 4):** 이론 위주의 기본 교수설계에서 **SAM(애자일 프로토타입) 및 PBL 모델**로 매핑 가중치를 자동 재계산하고, 제안서 내 교육 설계 철학 서술을 실습 지향형으로 자동 수정.
     - **순전파(Step 7):** 단순 1단계 반응 만족도 평가 중심에서 **2단계(학습 성취도 산출물 평가) 중심**으로 평가 계획 지표를 자동 승격.

## 4. 정합성 검증 지표 및 예외 경고 (Coherence Metric)

에이전트는 최종 PPTX 렌더링 데이터(JSON) 패키징 전, 제안서 내에 논리적 모순이 존재하는지 아래 2대 모순 필터로 전수 검사한다.

1. **대상-난이도 불일치 검사 (Audience-Level Clash):**
   * **진단:** 대상 수강생 수준이 '비전공자/초급'인데 커리큘럼에 'Python 코딩', 'AI 에이전트 직접 코딩 구축' 등 무거운 실무가 포함되어 있는가?
   * **조치 유형: 경고 + 자동 수정**
     - 사용자 승인 없이 커리큘럼을 "핵심 개념 데모 + 활용 시나리오 체험" 형태로 자동 경량화
     - 기획서 하단에 `[에이전트 자동 조정]` 주석 첨부: "초급 대상에 맞춰 코딩 실습을 데모 시연으로 전환하였습니다. 원래 내용을 유지하려면 수동 수정하세요."

2. **대상-피치 스타일 정합성 진단 (Audience-Pitch Mismatch):**
   * **진단:** 교육 대상이 '현업 실무진/개발자'인데 `pitch_style`이 `HEAVY_ACADEMIC`으로 설정되었는가?
   * **조치 유형: 경고만 (자동 수정 안 함)**
     - 사용자에게 경고 출력: "현업 실무진 대상이므로 `LIGHT_AGILE` 스타일을 권장합니다. 현재 설정을 유지하시겠습니까?"
     - 사용자 확인 없이 pitch_style을 변경하지 않음 (피치 스타일은 전략적 결정이므로 사용자 권한 보장)

3. **신규: 도메인-커리큘럼 미연동 감지 (Domain-Curriculum Misalignment):**
   * **진단:** 고객사 도메인이 "금융/보험"으로 명시되었으나 커리큘럼 내 실습 시나리오에 Skill 05 Section 4의 금융 도메인 키워드(여신 심사, 약관, 리포트)가 0건인가?
   * **조치 유형: 자동 수정**
     - Skill 05 Section 4의 해당 도메인 시나리오 템플릿을 CURRICULUM_TABLE rows에 자동 삽입
     - 삽입 후 Skill 06 AS 재검증 실행
