# Agent Skill 09: Pipeline Orchestration & Integrity Pass Rules (V12 — 4-Phase)

## 1. 개요

본 사양은 B2B 교육 제안서 생성 파이프라인의 전체 실행 순서, 단계별 사용자 승인 게이트(GATE), 자가 검증 루프를 정의한다.

**핵심 원칙:**
- 각 GATE에서 사용자의 명시적 승인 없이는 다음 단계로 진행하지 않는다.
- 각 Phase 내에서 자가 검증을 반드시 실행하고 결과를 사용자에게 공개한다.
- FAIL 항목이 있으면 자가 수정 후 재검증하고, 3회 이후에도 FAIL이면 사용자에게 수동 확인을 요청한다.
- Phase 4(렌더러/PPTX 자동 생성)는 파이프라인에서 제거되었다. 최종 산출물은 `03_content.md`이며 디자인·PPTX 제작은 사용자가 직접 수행한다.

## 6. FAIL 처리 및 Self-Correction 루프

- `[CV: FAIL]` 감지 시: 해당 항목을 자가 수정 후 해당 항목만 재검증한다. 3회 재시도 후에도 FAIL이면 사용자에게 수동 확인을 요청한다.
- 사용자 수정 피드백 수신 시: `Skill 10 Dependency Map`을 발동하여 연관 단계 전체를 재검증한다.
- **GATE에서 사용자가 'back'을 입력하면** 이전 Phase로 돌아가 해당 Phase부터 재실행한다.
