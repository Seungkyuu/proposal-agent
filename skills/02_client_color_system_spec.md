# Agent Skill Extension: Client Brand Color Auto-Extraction & Palette System

## 1. 개요 (Overview)
본 사양은 에이전트가 고객사(제안 대상 기업)의 고유 브랜드 컬러(CI/BI)를 자동으로 서치 및 분석하고, 이를 비즈니스 제안서 전반에 걸쳐 세련되게 적용하기 위해 '안정적인 색상 팔레트'로 가공 및 매핑하는 기술적 규칙을 정의한다.

---

## 2. 컬러 수집 및 추출 파이프라인 (Color Discovery Pipeline)

에이전트는 **Step 2(제안 배경 기획)** 단계에서 비즈니스 분석과 동시에 아래의 로직을 통해 고객사의 대표 색상을 확보한다.

```
[고객사명 입력]
│
├── 1단계: 웹 검색 엔진 가동 ("{고객사명} CI 색상 코드", "Brand Identity Hex", "Logo Color")
│     └── 공식 가이드라인 문서를 우선 탐색하여 공식 HEX 코드 수집.
│
├── 2단계: 공식 홈페이지 / 로고 이미지 수집 및 비전 분석 (Fallback)
│     └── 공식 로고 파일 다운로드 후 ColorThief 라이브러리 또는 Vision API를 통해
│         지배적인 도미넌트 컬러(Dominant Color) 추출.
│
└── 3단계: 컬러 유효성 검증
      └── 지나치게 밝은 형광색이나 흰색/검은색 계열이 키 컬러로 잡히지 않도록
          채도와 명도 필터링 수행.
```

## 3. 비즈니스 제안서용 '60-30-10 팔레트' 변환 규칙

고객사 로고의 원색을 그대로 슬라이드 넓은 면적에 바르면 가독성이 무너진다. 에이전트는 추출된 키 컬러를 비즈니스 디자인의 황금 비율인 **60-30-10 법칙**에 맞게 조율하여 팔레트를 재구성해야 한다.

| 역할 | 적용 비율 | 정의 및 컬러 선택 규칙 | 실제 슬라이드 내 적용 대상 |
| :--- | :---: | :--- | :--- |
| **Dominant (지배색)** | **60%** | 슬라이드의 배경 및 뼈대 바탕이 되는 색상.<br>눈의 피로도를 최소화하는 뉴트럴 톤. | - 밝은 테마: Off-White (`#F8FAF8`), Light Gray (`#F1F5F9`) 등<br>- 어두운 테마: Dark Charcoal (`#0B0F19`), Deep Navy (`#0F172A`) 등 |
| **Sub (보조색)** | **30%** | 본문 텍스트, 카드 컴포넌트의 테두리, 표의 헤더 배경.<br>지배색과 대비를 이루는 차분한 톤. | - 본문 텍스트: Slate Gray (`#334155` 또는 `#94A3B8`) 등<br>- 카드 배경: 아주 옅은 그레이나 다크 블루 계열 |
| **Accent (강조색)** | **10%** | **★ 추출된 고객사 고유 브랜드 컬러 적용.**<br>시선을 단번에 사로잡는 하이라이트 영역. | - 핵심 수치, 중요 키워드 볼드 처리, 타임라인 노드, 액티브 탭(Tab) 배경 |

## 4. 데이터 전송 규격 (JSON Schema 확장)

에이전트가 Step 8(최종 렌더링) 단계에서 생성하여 백엔드 렌더러로 전달할 최종 JSON 데이터에 아래와 같이 추출 및 계산된 RGB/HEX 컬러 메타데이터를 포함한다.

```json
{
  "design_system": {
    "theme_type": "LIGHT",
    "color_palette": {
      "client_raw_color": "#10B981",
      "dominant_bg": "#F8FAF8",
      "sub_text": "#334155",
      "accent_color": "#10B981",
      "accent_rgb": [16, 185, 129]
    }
  },
  "slides": [
    {
      "slide_number": 3,
      "layout_type": "PROBLEM_VS_SOLUTION",
      "title": "S사의 지속 가능한 성장을 위한 AX 솔루션",
      "content": {
        "left_block": {
          "title": "현재의 한계 (As-Is)",
          "bullets": ["단순 반복 행정 업무로 인한 병목 현상"]
        },
        "right_block": {
          "title": "교육 후 미래 (To-Be)",
          "bullets": ["업무 자동화 Bot 도입을 통한 시간 단축"]
        }
      }
    }
  ]
}
```

## 5. 파이썬 백엔드(python-pptx) 렌더링 매핑 가이드라인

백엔드 엔진은 전달받은 JSON의 `"color_palette"`를 감지하여 템플릿의 서식을 동적으로 덮어쓴다.

1. **텍스트 하이라이트 제어 (`RGBColor` 연동):**
   * 에이전트가 특정 단어에 볼드 및 하이라이트 플래그를 심어두었거나, 카드의 `"highlight": true` 속성을 준 경우 렌더러는 폰트 컬러를 설정할 때 `RGBColor(*accent_rgb)`를 대입하여 고객사 컬러를 강제 적용한다.

2. **도형 테두리 및 구분선 제어:**
   * 슬라이드 상의 주요 구분선(`connector`)이나 표(`table`)의 강조 행 테두리에 `accent_color`를 입힌다.

3. **표지 및 간지 데코레이션:**
   * 표지 슬라이드 우측 상단이나 좌측 하단의 브랜드 포인트 데코 도형의 채우기 색상(Fill Color)을 `accent_color`로 동적 변경한다.
