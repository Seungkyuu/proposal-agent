# Agent Skill: Instructional Design Model Selection & Search Engine

## 1. 개요 (Overview)
본 사양은 에이전트가 Step 4(교육 설계) 단계를 수행할 때, 요구사항 분석 결과를 바탕으로 최적의 교수설계 모델(Instructional Design Model)을 알고리즘적으로 매핑하고 구체적인 커리큘럼 아키텍처로 변환하기 위한 기술적 규칙을 정의한다.

---

## 2. 탑재할 교수설계 모델 라이브러리 (Model Library)

에이전트는 아래 5가지 핵심 교수설계 모델의 정의, 목적, 적용 방식을 지식 베이스(Knowledge Base)에 내재화한다.

1. **역방향 설계 모델 (Backward Design)**
   * **철학:** "원하는 최종 비즈니스 결과(Outcome)를 정의하고, 이를 달성하기 위한 평가 기준을 먼저 세운 뒤, 커리큘럼을 역산하여 설계한다."
   * **적용 대상:** 생산성 지표 향상, 시간 절감 등 명확한 ROI 산출이 필요한 직무 교육.

2. **SAM 모델 (Successive Approximation Model - 애자일 교수설계)**
   * **철학:** "기획-설계-개발을 선형적으로 진행하지 않고, 프로토타입을 빠르게 만들어 반복 피드백을 수용하며 점진적으로 완성한다."
   * **적용 대상:** 기술 변화 속도가 빨라 즉각적인 툴 실습과 반복적 결과물 피드백이 중요한 AX/IT 실무 교육.

3. **PBL 모델 (Problem-Based Learning - 문제 해결형 학습)**
   * **철학:** "실제 현업의 미해결 과제(Problem)를 제시하고, 학습자가 주도적으로 해결책을 도출하는 프로젝트 중심 학습."
   * **적용 대상:** 팀장급 이상의 전략 수립 과정, 해커톤, 사내 과제 해결형 액션 러닝(Action Learning).

4. **ADDIE 모델 (전통적 체계적 교수설계)**
   * **철학:** "분석(A) -> 설계(D) -> 개발(D) -> 구현(I) -> 평가(E)의 5단계 정석 파이프라인에 입각해 빈틈없는 교육 프레임워크를 수립한다."
   * **적용 대상:** 전사 임직원 대상 공통 역량 교육, 신입사원 입문 교육, 장기 로드맵 교육.

5. **Gagne(가네)의 9가지 교수사태 (9 Events of Instruction)**
   * **철학:** "주의 집중부터 일반화까지 인간의 내적 학습 과정을 자극하는 9가지 수업 사태를 설계하여 단기 학습 몰입도를 극대화한다."
   * **적용 대상:** 단기 특강(1일 2~4시간), 핵심 개념 전달 위주의 세미나성 교육.

## 3. 교수설계 모델 자동 매핑 알고리즘 (Selection Logic)

에이전트는 임의로 모델을 선택하지 않고, 고객의 인풋 데이터로부터 매핑 점수 M을 계산하여 가장 점수가 높은 모델을 선정한다.

### [의사결정 변수 정의]
* **목표 유형 (O ∈ {1, 2, 3, 4}):**
  - 1: 마인드셋/개념 학습, 2: 도구 숙달/실습, 3: 현업 실전 적용, 4: 비즈니스 문제 해결
* **교육 기간 (D ∈ {1, 2, 3}):**
  - 1: 초단기 (1일, 8시간 이하), 2: 단기 (2~5일), 3: 중장기 (1주일 이상)
* **평가 엄격도 (A ∈ {1, 2, 3}):**
  - 1: 단순 만족도 조사, 2: 과제/포트폴리오 평가, 3: 비즈니스 ROI 산출 (비용/시간 절감량)

### [수학적 매핑 모델 (Mapping Score Formula)]
각 교수설계 모델 k에 대한 매핑 적합도 점수 M_k는 다음과 같이 정의된다.

```
M_k = w1 * O_k(O) + w2 * D_k(D) + w3 * A_k(A)
```

이때 가중치: w1 = 0.5, w2 = 0.25, w3 = 0.25
에이전트는 max(M_k)를 만족하는 교수설계 모델 k를 최종 채택한다.

### [실무형 단순 판단 매핑 트리 (Decision Tree Fallback)]
수식 연산 이후, 직관적 검증을 위해 아래 매핑 규칙을 크로스 체크한다.

* **Q1. 교육 목적이 구체적인 업무 성과(시간/비용 절감)인가?** ➔ YES ➔ **[역방향 설계 모델]** 우선 검토
* **Q2. 교육 기간이 1일(8시간) 이하의 특강성 교육인가?** ➔ YES ➔ **[가네의 9가지 교수사태]** 우선 검토
* **Q3. 교육 형태가 '해커톤' 또는 '사내 과제 해결' 중심인가?** ➔ YES ➔ **[PBL 모델]** 우선 검토
* **Q4. 교육 대상이 최신 개발/AI 툴 실습 위주인가?** ➔ YES ➔ **[SAM 모델]** 우선 검토
* **그 외 일반적인 전사 역량 교육인가?** ➔ YES ➔ **[ADDIE 모델]** 적용

## 4. 특수 도메인 커리큘럼 자동 탐색 및 서칭 규칙 (Knowledge Search)

만약 에이전트가 "바이오 제약 연구원을 위한 AI 가속화 과정"과 같이 생소한 도메인 교육 요구사항을 수신했을 때, 에이전트는 자체 지식을 활용하여 다음과 같이 커리큘럼 소스를 수집하고 검증한다.

```
[생소한 도메인 요구사항 접수]
│
├── 1단계: 타겟 도메인 키워드 조합 검색
│     - 예: "Biomedical researcher AI training curriculum", "바이오 AI 신약개발 교육과정"
│
├── 2단계: 최신 아카데믹/글로벌 교육 트렌드 분석
│     - Coursera, edX, 우수 대학(MIT, Stanford 등)의 유사 과정 실러버스(Syllabus) 파싱
│
└── 3단계: 융합형 커리큘럼 구조화
      - [도메인 기초 이론 -> AI 기술 매핑 -> 직무 맞춤형 실습 -> 최종 현업 과제 적용(PBL)]
```

## 5. 최종 제안서 내 교수설계 명문화 프롬프트 규칙 (Prompting Rules)

에이전트는 선정된 교수설계 모델을 제안서 텍스트로 녹여낼 때, "우리는 이 교육을 설계하기 위해 철학적인 근거를 가지고 접근했습니다"라는 뉘앙스를 교육담당자가 어필할 수 있도록 아래 서식을 필히 준수한다.

### [작성 예시 - 역방향 설계 적용 시]
> **슬라이드 메시지 (30pt):** 비즈니스 성과를 담보하는 **결과 지향적 역방향 교수설계(Backward Design)** 적용
>
> **카드 헤더 (18pt):** 교육 전 설계 ➔ 성과 목표 합의 ➔ 실전 적용 평가
>
> **본문 설명 (14pt):**
> * **목표 설정:** 사내 반복 업무의 **30% 자동화 시간 단축**을 최상위 목표로 설정
> * **평가 설계:** 교육 종료 시 만족도 조사를 넘어, **업무 자동화 Bot 포트폴리오** 실물 심사
> * **학습 계획:** 현업 밀착형 데이터 연동 실습 및 에이전트 구현 중심의 차시 배치
